# Contributing

Thank you for your interest. This is a portfolio source repository, so please open an issue before starting a substantial change.

## Development workflow

1. Create a focused branch from `main`.
2. Keep credentials and local databases out of commits.
3. Preserve source URL, observation date, geography, status, and confidence for new data.
4. Use primary-source evidence for investment projects. Announcements must remain `ANNOUNCED` until a primary source confirms progress.
5. Run the relevant Python and web checks described in the README.
6. Explain data-contract or methodology changes in the pull request.

Do not contribute proprietary listing feeds, restricted contact data, or third-party datasets that cannot be redistributed.
