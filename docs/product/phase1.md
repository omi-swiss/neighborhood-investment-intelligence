# Phase 1 implementation status

## Implemented vertical slice

The Opportunity Screener now has a deployable web implementation backed by a reproducible
Washington, DC pilot extract:

- 165 real census tracts with 2020-vintage simplified boundaries
- current ACS 2023 profile values and 2019–2023 historical observations
- city and Washington metro cohort medians
- transparent balanced-opportunity score with six categories and visible weights
- search, combined filters, sort, pagination, table, boundary map, and synchronized selection
- area detail, trend, source, geographic resolution, availability, and quality context
- private saved areas and saved filter sets using authenticated D1 records
- build, type, lint, rendered-route, API, and detail-route tests

The web extract is generated by `scripts/export_web_phase1.py`. It is intentionally bounded; the
national warehouse is not shipped to the browser.

## Remaining Phase 1 expansion

The acceptance criteria are functional for the pilot. Expansion work remains within Phase 1:

- publish all supported U.S. tracts through the planned FastAPI/PostGIS serving boundary
- add city/metro/ZIP selectors beyond the Washington pilot
- add editable strategy versions after default weights receive domain-owner approval
- implement CSV export as a data file rather than printable current view
- add national vector-tile serving and query/load tests at full warehouse volume
- add the full Data & Methodology and Data Health pages

Unsupported private-property, environmental, regulation, and tract-crime signals remain disabled.
They are not Phase 1 acceptance blockers and are not inferred.
